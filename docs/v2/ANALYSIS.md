# ETHGlobal Tokyo 2026 — what the results say (summary)

Analyst: Hideki Tamae · verified 2026-09-30 against primary sources.
Full two-page report: *ETHGlobal Tokyo 2026 — Full Analysis* (JA/EN PDF, shared separately).

**Facts**
- 504 hackers, 254 projects (199 new, 55 continuity), 8 finalists, 25 sponsor-prize winners from 7 sponsors. All results provisional until ETHGlobal's verification; payout planned for end of October.
- Finalists: Kura, Takarabako, Omamori, Patio Station, Yohaku, watermark, Enconomy, OddsFlow. Only 4 of them also won sponsor prizes; 21 of 25 sponsor winners were not finalists.
- Kura was the only project that was both a finalist and the top sponsor-prize earner ($4,000: Uniswap 1st + ENSv2 3rd). ETHGlobal does not rank finalists.
- HAIS Agent (this repo) was not a finalist and won no sponsor prize. No official reason is published.

**Closest projects to HAIS Agent**
1. **Airlock** — human-consent gateway for AI agents (redaction, re-identification check, ENSv2 policy, World ID approval, hash-chained audit). Won World "Best Use of World ID for Agents". → v2 architecture.
2. **Yohaku** (finalist) — routes agents' requests for human experience to auto/human/deny, fail-closed, x402 settlement. → v2 decision router; Phase 3 business model.
3. **Omamori** (finalist) — the agent never touches money outside a human-approved intent; shown live, including refusals. → v2 demo style.

**Analysis (not official)** — likely reasons HAIS Agent was harder to evaluate: the result was invisible on screen, there was no money flow, sponsor requirements (e.g. a live denial path) were not shown clearly, and the Showcase text was short. v2 addresses the first and third directly.

Sources: https://ethglobal.com/showcase · https://ethglobal.com/events/tokyo2026/prizes · Closing Ceremonies, Kartik Talwar (https://youtu.be/XLFyrOE19N8) · project pages for Airlock, Yohaku, Omamori, Kura.
